# Windows x64 安装验收

在 Windows 10 或更高版本 x64 设备上分别检查 NSIS EXE 与 MSI：

- [ ] SHA-256 与 `SHA256SUMS.txt` 相符；
- [ ] 文件名和安装程序版本为 `1.19.0`；
- [ ] 安装、启动、升级与卸载正常；
- [ ] 开始菜单、图标、产品名和 `.lmind` 文件关联正确；
- [ ] 打开 / 保存 / 自动保存、中文输入、文件对话框和打开目录正常；
- [ ] `Ctrl+K`、大纲、小地图及插件运行器回归正常；
- [ ] Python 自动检测与 executable 插件仅接受可信 `.exe`；
- [ ] 记录设备、Windows 版本、包 SHA-256 和验收人。

Windows 代码签名可作为后续增强；未签名不影响本批 Artifact 构建，但不能虚称已签名。
