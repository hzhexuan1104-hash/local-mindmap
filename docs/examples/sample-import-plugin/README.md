# JSON 分支导入示例

1. 在「插件 → 插件管理」的「已安装插件」页点击「导入本地插件」，选中本目录的 `manifest.json`。安装时会同时复制同目录的 `main.js`。
2. 启用脚本运行器，并确认插件已启用。
3. 在画布中选中目标节点，从「文件 → 导入」选择「JSON 分支导入…」，再选本目录的 `branches.json`。

示例把「项目计划 → 准备阶段 → 收集需求」等分支原样追加到选中节点下，并支持一次撤销。更换 `children` 数组可增加层级；可选的 `remark` 和 `type` 分别设置 Markdown 备注和已有节点类型 ID。详见[插件开发文档](../../plugin-development.md#导入插件)。
