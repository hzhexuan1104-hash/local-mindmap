# 命令面板

Local Mindmap v1.18.0 提供纯本地命令面板，把已有菜单、节点导航、最近文件、模板、节点类型和插件命令汇集到同一个键盘优先入口。命令面板只负责注册、搜索、展示、可用性判断和调用现有业务入口，不复制文件、节点、模板或插件执行逻辑。

模板库、查找、替换、大纲导航、节点类型管理和设置均调用与顶部菜单相同的统一工作面板入口；不会恢复已移除的左侧竖栏。插件管理命令继续打开现有插件管理界面。

顶部菜单的二、三级分组只影响结构化浏览；命令面板仍按最终 command id 直接搜索、执行和记录历史/收藏，不要求用户逐级展开菜单。

## 打开与操作

- 主快捷键：Windows / Linux 使用 `Ctrl+K`，macOS 使用 `Meta+K`。
- 备用快捷键：`Ctrl+Shift+P` / `Meta+Shift+P`。
- 帮助菜单中也提供“命令面板（Ctrl+K）”。
- `↑` / `↓` 选择，`Home` / `End` 跳转，`Enter` 执行，`Esc` 关闭，`Tab` / `Shift+Tab` 在面板内循环焦点。
- 打开后输入框自动聚焦；关闭后恢复原焦点。节点编辑器打开面板时暂停 blur 提交，避免丢失内容或重复生成 undo history。

## 搜索范围

无前缀时统一搜索允许的全部结果。以下前缀可快速限定范围：

- `>`：只搜索内置与插件命令。
- `@`：只搜索当前导图节点，标题和备注均进入索引，列表不展示完整备注。
- `#`：只搜索最近文件。
- `:`：只搜索插件命令。

搜索支持中文子串、英文大小写不敏感、多关键词和简单模糊匹配。排序依次考虑标题完全匹配、标题前缀、标题子串、关键词、分类、说明、最近使用、收藏、当前上下文和禁用惩罚；同分时保持注册顺序，避免列表跳动。高风险和 critical 插件命令不会仅因最近使用而置顶。

## 动态结果

- 节点：复用 v1.16 的运行时 `mindmapIndex` 和统一 `locateNode`。搜索索引在导图状态变化时构建，输入使用 100ms debounce；空查询不列出全部节点，结果最多渲染 50 项。
- 最近文件：显示文件名与脱敏位置；健康检查异常时显示“文件已移动或删除”，并提供复用现有逻辑的重新定位和移除结果。
- 模板：搜索名称、分类和说明，执行时调用现有模板应用逻辑及未保存确认。
- 节点类型：有选中节点时调用现有批量应用入口；无选中节点时打开全局节点类型管理。
- 插件：从 enabled 且 manifest 有效的菜单贡献生成稳定命令 ID。Script / external runner 关闭时显示禁用原因；未信任和高风险命令显示来源与风险，并继续进入现有确认、权限和 action 校验流程。

## 本地设置与隐私

命令面板设置保存在用户目录 `config/command-palette-settings.json`，Web fallback 仍使用统一用户数据存储层。可配置快捷键开关、最近命令、最近文件、节点结果、插件命令、执行后自动关闭，并可清空最近命令。

最近命令只保存：

```json
{
  "commandId": "builtin.file.save",
  "lastUsedAt": "2026-07-13T12:00:00.000Z",
  "useCount": 3
}
```

不会持久化搜索关键词、节点标题、节点正文、备注、文件绝对路径或命令动态参数。节点定位、模板、节点类型与最近文件等动态结果不会写入永久命令历史。命令搜索性能诊断如需记录，只允许记录耗时和数量，不记录查询内容。

## 安全边界

命令面板不绕过：

- 新建、打开、最近文件和模板覆盖时的未保存确认；
- 删除节点、版本恢复、草稿与插件危险操作确认；
- Script / external runner 开关；
- 插件 trusted、permissions、风险确认与宿主 action 校验；
- Workflow 和外部命令批量 action 的单次 undo batch。

命令执行异常会转换为本地 toast；插件异常继续写入既有插件日志。面板不会联网，不读取远程市场，也不修改 `.lmind` 或 `.lmplugin` 格式。
