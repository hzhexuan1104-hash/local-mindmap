# 使用指南

## 新建、打开与保存
通过“文件”新建空白导图或从模板库创建。打开本地 .lmind 文件可恢复节点、备注、样式与附件。Ctrl+S 保存；首次保存选择本地路径。建议在重要修改后及时保存，可在最近文件和版本历史中找回此前内容。

## 编辑节点
双击节点编辑文字。Tab 添加子节点，Enter 添加同级节点，Shift+Enter 在编辑文字时换行。删除键删除选中节点，Ctrl+Z 撤销，Ctrl+Y 重做。复制、剪切、粘贴可用于分支。拖动节点调整结构；框选可批量操作。

## 画布与布局
使用画布工具缩放、居中和全屏展示；拖动画布平移。布局菜单支持自动布局和自由布局。折叠分支可隐藏子节点，再次展开恢复展示。

## 节点样式与类型
在属性面板调整文字、背景、边框及连接线。节点类型管理支持建立可复用的样式与默认内容。通过“新建子节点默认类型”设置后，Tab 创建子节点会采用该类型。类型包可从本地文件导入或导出。

## Markdown 备注
选中节点后打开备注编辑区域。支持标题、加粗、列表、任务列表、引用、代码块和表格。预览可独立放大，适合阅读较长备注。Ctrl+B、Ctrl+I、Ctrl+K 分别用于相应编辑快捷操作。

## 查找与替换
Ctrl+F 打开查找替换，输入关键词后切换结果定位节点。可按节点文本或备注筛选、区分大小写。全部替换前请确认范围与数量，误操作可撤销。

## 附件
在节点附件入口添加链接、图片或文档，每个节点一个附件。链接使用 HTTP/HTTPS；本地附件随 .lmind 保存。点击图片附件可在软件内预览、缩放、旋转；其他附件由系统处理。

## 模板和导入导出
可保存当前导图为模板并在模板库复用。支持 Markdown、Excel、JSON 等导入导出；Excel 导入可配置列映射。导出选中节点会包含对应子分支，图片导出用于分享画布。

## 插件
插件管理包含配置、已安装插件和商城。可导入本地插件包并查看详情、启用或禁用。脚本和外部命令运行器默认关闭；仅为可信插件开启。开发者工作台可创建、校验、打包项目，协议详见插件开发文档。

## 数据与离线使用
核心功能不依赖云端。导图保存在本地 .lmind 文件；公共资源商城仅在主动查询或下载时访问配置地址，不上传导图或附件。迁移设备时请同时备份导图和需要复用的模板、类型与插件。
